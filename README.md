# John Darby — Premium portfolio with coffee motion

Open `index.html` to preview without any software.

This version intentionally preserves the approved *second screenshot* as the visual hero (including the same character, layout, fonts, project thumbnails, colors and metrics), rather than replacing it with a simple vector drawing. The screenshot is used as a static image for pixel-level visual fidelity; the website layers moving steam and light over the coffee area, clickable hotspots, and fully HTML project/approach sections underneath.

**Animation limitation:** A single still image cannot produce genuine arm-lifting/sipping animation. That requires a layered illustration, separate character frames, or a short animation/video asset. This version adds subtle cup/steam motion without changing the approved image. Reduced-motion preferences are supported.

The hero text is embedded in the reference image, while the accessible text and live links are available in HTML below. On narrow screens the hero is centered/cropped rather than reflowing. No changes were pushed to GitHub.

Update: Removed H-1B / relocation wording from the hero graphic. The character is still static; realistic sipping requires a separately animated character asset or video.
