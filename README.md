# John Darby animated portfolio

A responsive single-page portfolio with scroll reveal animations, project cards, experience, skills, and live links.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish with GitHub Pages
Create a public repository, upload `index.html`, then in Settings > Pages choose Deploy from a branch, `main`, root.

## Customize
Edit the project descriptions, work experience, and links in `index.html`. Add a verified email or LinkedIn URL to the Contact section if desired.

The referenced PDF guide was not available during creation, so this is an original starter design, not a reproduction of that guide.
